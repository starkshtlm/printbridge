# Screenshots for SETUP.md

9 pictures, all from real screens. Take them while you do the setup yourself — that
is the only time they are free. Drop the PNGs in this directory with exactly these names and
[SETUP.md](../SETUP.md) picks them up with no other change.

Blur anything secret: passwords, the part of a connector link after `/mcp/`, your public IP.

|---|---|

| `02-first-machine.png` | the Machines page at login.tailscale.com/admin/machines showing your phone or laptop as the only entry. |
| `03a-udm-ssh.png` | the Control Plane → Console → Advanced page with the SSH toggle on and the password field filled (blur the password). |
| `03b-pi-imager.png` | the Imager's settings dialog with "Enable SSH" ticked and a username set. |
| `03c-approve-route.png` | the "Edit route settings" panel with the printer's /32 route toggled on. |

| `04a-create-server.png` | the provider's create-server page with Ubuntu selected and the smallest size highlighted. |
| `06a-claude-connector.png` | the "Add custom connector" dialog with the URL field filled (blur the key part after `/mcp/`) and no authentication selected. |
| `06b-chatgpt-connector.png` | the connector creation form with the URL filled (blur the key) and "No authentication" selected. |
